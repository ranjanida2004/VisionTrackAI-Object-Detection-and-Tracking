# 🚀 VisionTrack AI – Object Detection & Tracking

VisionTrack AI is a Computer Vision project that performs **real-time object detection and tracking** in uploaded videos using **YOLOv8** and **DeepSORT**.

It provides an interactive **Gradio Web Interface** where users can upload a video and get:

- A processed video with bounding boxes and unique object IDs  
- A tracking summary report with total frames and detected objects  

---

## ✨ Features

✅ Object Detection using **YOLOv8**  
✅ Object Tracking using **DeepSORT**  
✅ Unique ID assignment for tracked objects  
✅ Total object counting across frames  
✅ Video output saved automatically  
✅ Simple and interactive UI built with **Gradio**  

---

## 🛠️ Technologies Used

- Python  
- OpenCV  
- NumPy  
- Ultralytics YOLOv8  
- DeepSORT Realtime Tracker  
- Gradio
